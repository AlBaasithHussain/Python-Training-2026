## Explanation

## Algorithm
1. Use a dictionary.
2. Check the complement for each element.
3. Return the indices.

## Brute Force
Use nested loops to compare every pair.

## Optimized Approach
Use a hash map for faster lookup.

## Time Complexity
O(n)

## Space Complexity
O(n)

## Sample Input
[2, 7, 11, 15], 9

## Sample Output
[0, 1]
